# Instalación y entorno de trabajo

APEX MOTOR se desarrolló utilizando WordPress dentro de un entorno local de laboratorio.

## Herramientas utilizadas

Para preparar el entorno se utilizaron las siguientes herramientas:

- XAMPP.
- Servidor web Apache.
- PHP.
- MySQL / MariaDB.
- WordPress.
- Navegador web.

## Preparación general

El proceso de preparación del entorno consistió en:

1. Instalar y preparar XAMPP.
2. Iniciar los servicios necesarios para el entorno web y la base de datos.
3. Crear una base de datos local para WordPress.
4. Instalar WordPress en el entorno de laboratorio.
5. Completar la configuración inicial del CMS.
6. Crear las páginas necesarias para el proyecto.
7. Configurar la navegación y personalización visual del sitio.

## Entorno local

El proyecto se ejecutó únicamente de forma local durante su desarrollo.

Este repositorio no incluye la instalación utilizada, archivos de configuración, credenciales, bases de datos ni código fuente del proyecto.

La documentación se centra en el proceso de trabajo y en el resultado final obtenido.

## Nota de seguridad

Los valores específicos utilizados durante la instalación no se documentan públicamente cuando pueden contener información del entorno de desarrollo.

Para los ejemplos se utilizan únicamente referencias genéricas y datos de demostración.
