# Seguridad y publicación del proyecto

Este repositorio es público, por lo que antes de publicar la documentación del proyecto se han aplicado varias medidas para evitar la exposición de información sensible.

## Información no publicada

El repositorio no contiene:

- Código fuente del sitio web.
- Instalación completa de WordPress.
- Archivo `wp-config.php`.
- Credenciales de acceso.
- Contraseñas.
- Bases de datos o exportaciones SQL.
- Copias de seguridad.
- Tokens o claves API.
- Información personal del entorno de desarrollo.
- Direcciones IP públicas.
- Archivos de configuración internos.

## Entorno de laboratorio

APEX MOTOR se ha desarrollado en un entorno local de laboratorio.

El uso de un entorno local permite realizar pruebas y configuraciones sin exponer directamente el proyecto a servicios públicos en Internet.

## Capturas y vídeo

Las capturas de pantalla y la demostración en vídeo incluidas en el repositorio han sido revisadas antes de su publicación.

Se ha evitado mostrar información como:

- Paneles de administración.
- Credenciales.
- Correos personales.
- Rutas locales del sistema.
- Información del equipo utilizado.
- Datos privados o identificativos.

Los datos visibles en formularios o direcciones de contacto son datos de demostración.

## Objetivo

El objetivo de estas medidas es poder mostrar el resultado del proyecto y el proceso de aprendizaje sin comprometer la seguridad ni publicar información innecesaria del entorno utilizado.
