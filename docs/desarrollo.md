# Desarrollo del proyecto

APEX MOTOR se ha desarrollado como proyecto académico utilizando WordPress en un entorno local de laboratorio.

## Preparación del entorno

Para el desarrollo se utilizó un entorno local con XAMPP, permitiendo trabajar con WordPress, PHP y una base de datos MySQL/MariaDB sin exponer el proyecto directamente a Internet.

## Creación del sitio

Durante el desarrollo se realizaron las siguientes tareas:

- Instalación y configuración inicial de WordPress.
- Creación de las páginas principales del sitio.
- Configuración del menú de navegación.
- Organización del contenido por secciones.
- Personalización visual del sitio.
- Creación de fichas de vehículos y comparativas.
- Creación de una guía informativa sobre conceptos del motor.
- Incorporación de un formulario de contacto de demostración.
- Revisión de enlaces internos y navegación entre páginas.

## Personalización

El sitio fue adaptado visualmente para mantener una estética relacionada con el mundo del motor, utilizando principalmente una combinación de colores oscuros, blancos y rojos.

También se trabajó la distribución de los contenidos para diferenciar claramente las distintas secciones del sitio.

## Entorno de trabajo

El desarrollo se realizó exclusivamente en un entorno local de laboratorio.

El código fuente, la instalación completa de WordPress y la base de datos no se publican en este repositorio.

Este repositorio se utiliza únicamente para documentar el proyecto, mostrar su estructura y presentar el resultado final.
